# Atlas — каталог сервисов Onym

Рабочий сайт: https://atlas.predhit.com · Панель владельца: https://atlas.predhit.com/admin

Atlas расширяет [референсный Onym Discovery](https://github.com/onymchat/onym-discovery) веб-каталогом и панелью владельца. Оригинальный Rust CLI сохранён: именно он подписывает, публикует и проверяет манифест и снимки каталога. Исходная лицензия MIT сохранена.

## Возможности

- Поиск, фильтры по роли сервиса, карточки, сравнение и история изменений.
- Добавление по HTTPS URL манифеста: новые записи автоматически публикуются после проверки подписи, срока и базового формата.
- Владелец редактирует название, описание, категорию и комментарий без изменения подписанного манифеста оператора; отключает и восстанавливает сервисы.
- Изменившиеся манифесты ожидают решения владельца. Недоступные и просроченные записи исключаются из подписанного снимка.
- Отключённый оператор не может обойти блокировку простым повторным добавлением под другим componentId.
- Почасовая проверка доступности, подписанные последовательные снимки, локальные резервные копии SQLite за 14 дней.

## Подключение в Onym

Добавьте поставщика Discovery по адресу `https://atlas.predhit.com/manifest.json`. Сверьте отпечаток ключа с окном «Подключить каталог» на сайте. Конкретные пункты меню зависят от версии клиента.

Автоматическое добавление означает прохождение технических проверок, а не рекомендацию сервиса, аудит безопасности или проверку соответствия всем профилям Onym. См. [политику](web/policy.md) и [конфиденциальность](web/privacy.md).

## Разработка

Требуются Rust stable, PHP 8.3 с curl, sodium, mbstring, PDO SQLite.

```sh
cargo build --release
cargo test
php web/tests/protocol.php
ATLAS_CLI="$PWD/target/release/onym-discovery" php web/tests/integration.php
mkdir -p .local/data
ATLAS_DATA="$PWD/.local/data" ATLAS_CLI="$PWD/target/release/onym-discovery" ATLAS_URL=http://localhost:8080 php web/bin/console.php init
ATLAS_DATA="$PWD/.local/data" php -S localhost:8080 -t web/public web/public/router.php
```

Начальный пароль хранится в `.local/data/initial-admin-password.txt`. Никогда не публикуйте каталог данных, ключи или пароли. Пример локальной среды использует HTTP только на localhost.

## Структура

- `src/`, `tests/`: исходный Rust publisher и тесты совместимости.
- `web/`: интерфейс, API, SQLite, проверка внешних манифестов и тесты Atlas.
- `ops/`: отдельный nginx virtual host, PHP-FPM pool и systemd timer.
- [Эксплуатация и развёртывание](docs/OPERATIONS.md).
- [Документация исходного CLI](docs/upstream-README.md).

Боевая ветка: `codex/production`. Развёртывание выполняется явно по проверенному коммиту. Workflow исходного проекта, обращавшийся к инфраструктуре Onym, отключён и сохранён только как исторический пример.
